# Промпт для AI-ассистента: Имплементация UI-компонентов и экранов

Ты — Senior React Developer. Твоя задача — аккуратно имплементировать UI-слой (компоненты и экраны) для проекта TON Testnet Wallet на основе готовых HTML/Tailwind шаблонов (дизайнов) и дизайн-документации.

## 1. Контекст проекта и Стек технологий
- **Фреймворк:** React 18 + TypeScript + Vite.
- **Стилизация:** Tailwind CSS (строго используется для всей стилизации, никаких сторонних UI-библиотек вроде Material UI или Ant Design).
- **Стейт-менеджмент:** Zustand.
- **Роутинг:** Wouter (или ручной роутинг, если указано).
- **Иконки:** Lucide Icons (`lucide-react`).
- **Специфика:** Минималистичный интерфейс, темная тема для MVP, адаптивность (mobile-first approach, расширяющийся по центру для десктопа).

## 2. Исходные материалы
У тебя есть доступ к следующим файлам:
1. **`docs/PLAN.md`** — План реализации. Тебя интересуют **пункты 8 (UI-компоненты)** и **9 (UI-экраны)**. Это твой пошаговый план работы.
2. **`docs/DESIGN_BRIEF.md`** — Подробное описание дизайн-системы (цвета, шрифты, отступы) и спецификация поведения каждого компонента и экрана. 
3. **`design/SCREENS_REGISTRY.md`** — Таблица маппинга экранов из ТЗ с конкретными папками их дизайнов.
4. **`design/stitch_create_wallet_step_1/*`** — В этих директориях лежат исходники готовых дизайнов. В каждой папке есть файл `code.html` со сверстанной версией экрана (HTML + Tailwind) и `screen.png` с визуалом.

## 3. Требования к коду
- **Tailwind:** Бери готовые классы из `code.html`, но переноси их в React-компоненты (`class` -> `className`).
- **Компонентный подход:** Не копируй HTML целиком в один файл. Выделяй переиспользуемые элементы (Button, TextInput, CopyButton, TransactionItem, PasswordInput, Modal и др.) в отдельные компоненты в папку `src/components`. Все они описаны в пункте 8 `PLAN.md`.
- **TypeScript:** Строгая типизация! Описывай `interface` для Props каждого компонента.
- **Дизайн-система:** В `DESIGN_BRIEF.md` описаны CSS-переменные (токены). Убедись, что Tailwind-конфиг (`tailwind.config.js`) настроен правильно, и используй семантические классы (например, `bg-surface`, `text-primary`, `text-error`), которые маппятся на эти переменные. Не хардкодь HEX-цвета напрямую в компоненты, если есть семантический токен.
- **Логика и Структура:** В экранах (`src/screens/*`) собирай UI из компонентов. Интегрируй их с состоянием (Zustand-сторы) там, где это требует `PLAN.md` (раздел 9). Если сторы еще не реализованы, используй заглушки (mock data).

## 4. Порядок работы

Работу необходимо выполнять строго по шагам, завершая один блок перед переходом к следующему:

### Шаг 1: Настройка Tailwind и Дизайн-системы
Изучи `DESIGN_BRIEF.md` (раздел 3). Обнови/задай `tailwind.config.js` и базовый `index.css`, определив все кастомные цвета из палитры (bg, surface, border, primary, success, warning, error, etc.) и типографику.

### Шаг 2: Базовые UI-компоненты (Пункт 8 из PLAN.md)
Реализуй общие компоненты в `src/components/`, опираясь на HTML-исходники из `design/stitch_create_wallet_step_1/component_sheet_ui_kit/code.html` и спецификацию `DESIGN_BRIEF.md` (раздел 4):
- Переиспользуемые кнопки (`Button`, `CopyButton`).
- Поля ввода (`TextInput`, `PasswordInput` с индикатором силы).
- Специфичные компоненты: `HighlightedAddress`, `WarningCard`, `Toast` и `Loader`.
- *Пиши код по одному компоненту за раз. Проверяй типизацию и гибкость пропсов.*

### Шаг 3: Экраны Онбординга (Пункт 9 из PLAN.md)
Опираясь на HTML из соответствующих папок в `design/stitch_create_wallet_step_1/`:
- `WelcomeScreen.tsx` (исходник: `welcome_screen`)
- `CreateWalletScreen.tsx` (включает шаги пароля и мнемоники)
- `ImportMnemonicScreen.tsx`

### Шаг 4: Основные экраны и Транзакции (Пункт 9 из PLAN.md)
- `MainScreen.tsx` (исходник: `main_screen`, использует `TransactionItem`)
- `ReceiveScreen.tsx` (исходник: `receive_screen`, нужен QR-код)
- `SendScreen.tsx` и `ConfirmScreen.tsx` (исходники: `send_ton_input`, `confirm_transaction`, плюс экраны результатов)
- `SettingsScreen.tsx` (исходник: `settings_screen`, а также модалки смены пароля и экспорта)
